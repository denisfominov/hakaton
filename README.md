# hakaton — Alpha Intelligence

Агент новостной аналитики для руководителей крупного бизнеса (выручка от 15 млрд ₽).
Кейс «Альфа Хак: Новостная аналитика», направление КИБ.

Описание — состояние ветки `main`. История изменений — только в [CHANGELOG.md](CHANGELOG.md).

> **Этот README — для команды:** как устроен проект, как мы работаем, где что лежит и что делаем дальше.
> README для жюри (назначение, запуск, переменные, сценарий проверки по формату сдачи) — задача D8a, пишем позже.

Состояние на **2026-10-22**: `main` после PR #40 плюс цепочка веток задачи C20 (C20.1–C20.9) — описание верно, когда
они слиты. Проверено тестами, сборкой, `demo_check` и замером ленты (ниже).

## Что это

Помощник для руководителя компании — клиента банка. Он сам собирает новости, выбирает важные для конкретной
компании, объясняет, чем каждая грозит или помогает, подкрепляет вывод аналитикой Альфа-Банка и предлагает, что
сделать. Вход — из Альфа-Бизнеса (интернет-банк для юрлиц). Сведения о компании — только из набора данных банка.

## Как устроено

Одно приложение, внутри — четыре сервиса (модули [backend/app/services/](backend/app/services/)), которые передают друг
другу готовые объекты по описанным форматам ([docs/CONTRACTS.md](docs/CONTRACTS.md)):

```
3 CSV банка ──► [1] профиль ──► факты о компании ──┐
RSS-ленты ────► [2] сбор новостей ──► новости ─────┴─► [3] сопоставление ──► [4] объяснение ──► агент ──► интерфейс
                                                       балл — правила,        для руководителя
                                                       связи — LLM
```

- **[1] Профиль** ([company_profile.py](backend/app/services/company_profile.py)) — только три файла набора банка. У
  каждого факта — файл, запись и поле; чего нет в данных — «нет данных», без догадок. Доля рынка — «нет данных»: объёма
  рынка в наборе нет, есть только место по выручке в выборке.
- **[2] Сбор новостей** ([news_collection.py](backend/app/services/news_collection.py)) — 18 RSS-лент, склейка
  перепечаток, сюжеты, достоверность. О компаниях ничего не знает.
- **[3] Сопоставление** ([news_matching.py](backend/app/services/news_matching.py)) — значимость считают правила
  ([scoring.py](backend/app/scoring.py)) по фактам профиля; связи «факт профиля + цитата из новости» и допущения
  находит одна из 6 разрешённых LLM, код проверяет каждую цитату. LLM балл не меняет.
- **[4] Объяснение** ([interpretation.py](backend/app/services/interpretation.py)) — понятный руководителю текст только
  из результата [3]: новых фактов нет, неуверенность помечена. Без LLM — по шаблону.
- **Агент** — своя логика, без фреймворков ([agent.py](backend/app/agent.py), [agent_tools.py](backend/app/agent_tools.py)):
  план, инструменты (в том числе сервисы 3 и 4 и поиск по аналитике банка), самопроверка, ответ на 6 вопросов.
- **LLM** (большая языковая модель) — не обязательна: без неё работают правила и шаблоны. С ней — только 6
  разрешённых моделей через [llm_client.py](backend/app/llm_client.py); бюджет 500 ₽ в день на всю команду.
  Своей обучаемой ML-модели в проекте нет (удалена в C20.2).
- **Фронтенд** (то, что видно в браузере) — [frontend/src/pages/](frontend/src/pages/): лента, событие (объяснение и
  связи с профилем), профиль из данных банка (только чтение), портфель, решения, банк, макет Альфа-Бизнеса.
- **Скрипты** — [backend/scripts/](backend/scripts/): проверка показа (`demo_check`), замер ленты
  (`eval_feed_diversity`), разметка, платная очередь (`daily_paid`).
- **Тесты** — [backend/tests/](backend/tests/), 288 проходят (2026-10-22, ветка C20.8); в том числе тест границ:
  профиль и сбор новостей не зависят друг от друга.

## Как запустить

```bash
docker compose up --build
```

Открыть http://localhost:8000 (API — `/api`, описание API — `/docs`). Без файла `.env` всё работает без LLM.
Запуск для разработки, тесты и настройки — в [CLAUDE.md](CLAUDE.md), раздел «Run».

Не в git (лежат только локально): PDF кейса и данные клиентов `df_*_hack.csv` в корне, PDF аналитики банка,
веса модели эмбеддингов e5, папка лекций, `.env`.

## Как мы работаем

- **Двое, две зоны.** Ч1 — «агент и интерпретация», Ч2 — «данные, поиск и качество». Чьи какие файлы —
  [docs/TASKS.md](docs/TASKS.md).
- **Одна задача = одна ветка = один PR.** Ветка — отдельная копия кода под задачу; PR — заявка влить её в
  основную версию `main`. PR создаёт и сливает человек на GitHub. Открытых PR — не больше двух на команду.
- **У каждой задачи — ID** (A8, C17, …) в [docs/TASK_REGISTER.md](docs/TASK_REGISTER.md). Новая задача — строкой в
  [docs/TASK_INBOX.md](docs/TASK_INBOX.md).
- **Ответы организаторов главнее наших догадок:** [docs/QUESTIONS.md](docs/QUESTIONS.md) (пересказ),
  [docs/ORGANIZERS_RAW.md](docs/ORGANIZERS_RAW.md) (дословно).
- **Платные вызовы LLM** — только после согласия и оценки цены; перед ручным вызовом — сообщение в чат команды.
- **ML-задачи** (машинное обучение) — сверяем с лекциями курса: [docs/ML_LECTURES_INDEX.md](docs/ML_LECTURES_INDEX.md).
- Правила для Claude — [CLAUDE.md](CLAUDE.md).

ручной ввод профиля удалены. Проверено:

- `demo_check` на данных кейса — 6 шагов из 7: шаг «отраслевой риск» не проходит — у металлотрейдера U_200890 новость

- точность ленты по черновой разметке моделей ([docs/GAP_ANALYSIS.md](docs/GAP_ANALYSIS.md)): 5 демо-клиентов — P@10
  0,32 → 0,34, ленты разных клиентов совпадают меньше (0,157 → 0,059); 25 других компаний — 0,256 → 0,176 (эта разметка
  набрана частично из верха прежней ленты и смещена в её пользу).

**Главные пробелы:**

1. Шаг показа «отраслевой риск» — нужно решение: принять новую ленту или использовать платежи как допущение о поставщиках.
2. Качество связей от модели не измерено и нет записанных ответов для показа без ключа — платная задача C20.10
   (≈ 25–30 ₽, только с согласия).
3. Аналитика банка ещё не встроена в цепочку сервисов — следующая итерация; пока блок «Как это оценивает банк» в
   ответе агента идёт отдельно.
4. Правила считают любую ВЭД экспортом: у клиента со странами ВЭД Киргизия и Казахстан появился риск «задержка
   экспорта в ЕС и Турцию».
5. README для жюри не написан — D8a; разметка людьми не закончена — A1.
