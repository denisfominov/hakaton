# Аналитика Альфа-Банка для агента (RAG)

Сюда кладутся аналитические материалы банка из приложения 2 кейса: PDF, `.txt` или `.md`
(обзоры по ставке, валюте, отраслям, макроэкономике). Можно указать другую папку переменной `BANK_DOCS_DIR`.

- Сами материалы в репозиторий не коммитятся (`*.pdf` в `.gitignore`).
- PDF кейса — картинки страниц без текстового слоя. Их нужно один раз распознать:
  `uv run --with "pypdf[image]==5.1.0" --with ocrmac python -m scripts.ocr_bank_docs <папка с PDF> --out data/bank`
  (macOS) или `--engine vl` (Qwen3-VL через шлюз). Рядом с PDF появится `<имя>.ocr.txt`; ссылки в ответах
  по-прежнему указывают на PDF и номер страницы.
- Индекс строится автоматически при первом запросе и пересобирается, когда файлы в папке меняются.
- Документ режется на фрагменты по ~900 символов с номером страницы; поиск — TF-IDF по леммам.
- Ответ агента в блоке «Как это оценивает банк?» цитирует только найденные фрагменты, со ссылкой
  на файл и страницу. Нет материалов по теме — агент так и пишет, позицию банка не придумывает.
- Проверить, что проиндексировано: `GET /api/bank-docs`.
