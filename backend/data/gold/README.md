# Ручная разметка (gold)

Эталон для проверки своих моделей на реальных новостях: 200–300 пар «клиент кейса × новость», размеченных
экспертом. **В обучение не попадает.** Пока размечено меньше 200 пар, метрики моделей подписаны «черновые».

1. Создать заготовку: `cd backend && python -m scripts.make_gold_template` → `data/gold/gold_pairs.csv`
   (250 пар; файл не коммитится — содержит признаки клиентов кейса).
2. Заполнить колонки для каждой пары (остальные — справка о клиенте и новости):

| Колонка | Значения | Вопрос эксперту |
|---|---|---|
| `relevant` | `1` / `0` | Стоит ли показывать эту новость ЛПР этой компании? |
| `relevance_grade` | `0`–`3` | 0 — не касается, 1 — косвенно, 2 — заметно, 3 — критично |
| `impact` | `risk` / `opportunity` / `neutral` | Для этой компании это риск, возможность или нейтрально? |
| `urgency` | `high` / `medium` / `low` | Реагировать в течение недели / месяца / держать в поле зрения |
| `category` | `economy`, `regulation`, `markets`, `companies`, `technology`, `supply_chain`, `investment`, `industry`, `other` | Тема новости |
| `annotator`, `comment` | текст | Кто размечал, почему |

3. Проверить модели: `python -m scripts.evaluate_models` → `docs/ML_EVALUATION.md` (релевантность: PR-AUC и
   Spearman по `relevance_grade`, тип влияния: macro-F1).

Пример строки — `gold_template.csv`.
