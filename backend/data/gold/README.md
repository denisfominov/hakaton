# Ручная разметка (gold)

> **Разметка командой с клавиатуры (A1):** 200 пар демо-клиентов, 4 файла по 65 пар, страница с клавишами 1/2/3 и
> Space — инструкция [docs/a/LABELING.md](../../../docs/a/LABELING.md). Сборка `--merge` пишет `gold_pairs.csv` в
> формате ниже.

Эталон для проверки ранжирования на реальных новостях: 200–300 пар «клиент кейса × новость», размеченных
экспертом. Своей ML-модели больше нет (удалена в C20.2): эталон нужен для замера скоринга по правилам (задача A2).
Файлы с разметкой не коммитятся — содержат признаки клиентов кейса.

Колонки для каждой пары (остальные — справка о клиенте и новости):

| Колонка | Значения | Вопрос эксперту |
|---|---|---|
| `relevant` | `1` / `0` | Стоит ли показывать эту новость ЛПР этой компании? |
| `relevance_grade` | `0`–`3` | 0 — не касается, 1 — косвенно, 2 — заметно, 3 — критично |
| `impact` | `risk` / `opportunity` / `neutral` | Для этой компании это риск, возможность или нейтрально? |
| `urgency` | `high` / `medium` / `low` | Реагировать в течение недели / месяца / держать в поле зрения |
| `category` | `economy`, `regulation`, `markets`, `companies`, `technology`, `supply_chain`, `investment`, `industry`, `other` | Тема новости |
| `annotator`, `comment` | текст | Кто размечал, почему |

Пример строки — `gold_template.csv`.
