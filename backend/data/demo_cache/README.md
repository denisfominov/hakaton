# Кэш ответов моделей для демонстрации без ключа

**Это не данные и не правила, а сохранённые ответы настоящих языковых моделей из списка кейса** (через шлюз
организаторов), полученные заранее скриптом `python -m scripts.warm_cache`. Ключ шлюза один на команду и отключается
после дедлайна — без этого кэша жюри не увидело бы ответ модели.

- Один файл — один запуск агента: `<профиль>__<событие>__<роль|any>.json`. Внутри: модель, версии промптов, дата
  получения, токены и стоимость, ответ по JSON-схеме и трассировка.
- Только демонстрационные клиенты кейса (`case-u-…`) и новости из подборки `data/real/news.json` (живые RSS быстро
  устаревают). Ответы на свои вопросы не кэшируются.
- Мок-ответы сюда не пишутся и не читаются (проверка в `app/demo_cache.py`).
- В интерфейсе такой ответ помечен: «Ответ из кэша: получен ранее моделью X, дата».
- Используется, только когда языковая модель не подключена. С ключом агент работает с моделью как обычно.

**Состояние на 2026-10-20: кэш пуст** — ключа шлюза у команды ещё нет, реальных вызовов моделей не было.
