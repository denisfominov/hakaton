фронтенда — в [frontend/package-lock.json](frontend/package-lock.json). Тексты лицензий поставляются вместе с пакетами.

## 4. Языковые модели

Используются **только модели из приложения 3 кейса**; список зашит в [backend/app/llm_client.py](backend/app/llm_client.py),
модель вне списка отклоняется до запроса. SDK внешних AI-сервисов (OpenAI, Anthropic и др.) и агентные фреймворки
не используются. Все модели вызываются только через шлюз организаторов; своего сервера моделей нет (сервис Ollama
удалён из docker-compose — docs/COMPLIANCE.md).

| Модель | Роль в сервисе | Как подключается |
|---|---|---|
| Gemma 4 26B A4B | `fast`: план агента | шлюз организаторов |
| GLM-5.3-Flash | `reasoning`: ответ агента и разбор события | шлюз организаторов |
| Qwen3.6 35B A3B | `default`; запасная для классификации и анализа | шлюз организаторов |
| DeepSeek-V4.1-Flash, Kimi-K2.6, Qwen3-VL-30B-A3B-Instruct | взаимосвязи, запасная модель, распознавание страниц-картинок | шлюз организаторов |

Точные имена моделей у шлюза и роли в роутере — [docs/COMPLIANCE.md](docs/COMPLIANCE.md). Размещение весов на своём
сервере — только предложение, не выполняется ([docs/FINETUNE_PROPOSAL.md](docs/FINETUNE_PROPOSAL.md)). Без LLM сервис полностью работает на правилах.

### Локальная модель эмбеддингов (не генеративная)

| Модель | Лицензия | Назначение | Как подключается |
|---|---|---|---|
| [intfloat/multilingual-e5-small](https://huggingface.co/intfloat/multilingual-e5-small), ревизия `614241f6`, ONNX int8 | MIT (проверено на карточке модели 2026-10-20) | поиск по аналитике банка и новостям (RAG), смысловая близость новости к профилю | веса скачивает `python -m scripts.download_embeddings` (sha256 проверяется), в репозиторий не коммитятся; в Docker — том или `--build-arg BAKE_EMBEDDINGS=1` |

Использование локальных моделей эмбеддингов разрешено организаторами; ограничение на шесть LLM к ним не относится.
Без весов поиск работает на TF-IDF.

| Шлюз LLM организаторов | разрешённые модели | 500 ₽ в день на ключ команды (сброс в 03:00 МСК), маскирование реквизитов перед отправкой |

## 7. Смоделированные интеграции

| Интеграция | Статус |
|---|---|
| API новостей и аналитики Альфа-Банка (`AlfaBankSource` в `backend/app/sources.py`) | каркас: формат ответа — наше предположение, доступа нет, не проверялась |
| Аналитика банка | RAG по файлам из `BANK_DOCS_DIR` вместо API банка |
| Главный экран Альфа-Бизнеса (`/alfa-business`) | **макет**: свои стили, без логотипов и фирменных файлов банка; счета, платежи и кредиты — заглушки |
| Токен входа из Альфа-Бизнеса | **заглушка**: подпись HMAC общим секретом `ENTRY_SECRET`, выпускает сам прототип (`/api/entry/mock-token`); в продукте токен выпускает банк (docs/ALFA_BUSINESS_ENTRY.md) |
| Роль пользователя в компании | **смоделирована**: выбирается на макете; в продукте её и связь пользователя с компанией подтверждает банк (docs/SECURITY.md) |
