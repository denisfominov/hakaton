# THIRD_PARTY_NOTICES

Точные версии Python-зависимостей зафиксированы в [backend/requirements.lock](backend/requirements.lock),
фронтенда — в [frontend/package-lock.json](frontend/package-lock.json). Тексты лицензий поставляются вместе с пакетами.

## 4. Языковые модели

Используются **только модели из приложения 3 кейса**; список зашит в [backend/app/llm_client.py](backend/app/llm_client.py),
модель вне списка отклоняется до запроса. SDK и API OpenAI и Anthropic не используются.

| Модель | Роль в сервисе | Как подключается |
|---|---|---|
| Gemma 4 26B A4B | `fast`: план агента | шлюз организаторов или свой сервер |
| GLM-5.3-Flash | `reasoning`: ответ агента и разбор события | шлюз организаторов |
| Qwen3.6 35B A3B | `default`; кандидат для своей LLM | шлюз или открытые веса под Ollama/vLLM |
| DeepSeek-V4.1-Flash, Kimi-K2.6, Qwen3-VL-30B-A3B-Instruct | разрешены, по умолчанию не используются | через `LLM_MODEL_*` |

Условия использования весов — по лицензии на карточке каждой модели; перед размещением весов на своём сервере
лицензию нужно проверить (см. [docs/OWN_LLM.md](docs/OWN_LLM.md)). Без LLM сервис полностью работает на правилах.

## 5. Данные

| Данные | Источник | Условия |
|---|---|---|
| Обезличенные данные о компаниях, связях с физлицами и платежах (`df_*_hack.csv`) | организаторы кейса «Альфа Хак» (приложение 1) | только для решения кейса; в репозиторий не коммитятся |
| Аналитические материалы Центра макроэкономических исследований Альфа-Банка (9 PDF) и их распознанный текст | организаторы кейса (приложение 2) | только для решения кейса; в репозиторий не коммитятся |
| Датасет для дообучения своей LLM (`backend/data/sft`) | собран нами из данных кейса | производный от данных кейса — только для решения кейса, не коммитится |
| Учебные материалы курса «Машинное обучение» (ИТМО) | предоставлены командой | использованы как методические указания, в репозиторий не коммитятся |
| Синтетический пример клиентов (`backend/data/clients/sample`) | сгенерирован нами (`scripts/make_sample_clients.py`) | свободно |
| Синтетические компании и новости (`backend/data/synthetic`) | созданы нами для тестов | свободно |
| Подборка реальных публикаций (`backend/data/real/news.json`) | Reuters, Интерфакс, Коммерсантъ, Ведомости, РГ, Банк России и др. | хранятся заголовок, ссылка на оригинал и краткий пересказ фактов своими словами; права на тексты — у изданий |
| Котировки (`backend/data/market`) | Московская биржа, ISS API | публичные данные, для анализа |
| История решений по ключевой ставке (`backend/data/history`) | Банк России, публичные пресс-релизы | публичные данные |
| Реестр изданий (`backend/data/outlets.json`) | составлен нами | свободно |

## 6. Внешние сервисы (по запросу пользователя)

| Сервис | Зачем | Ограничения |
|---|---|---|
| RSS изданий (`backend/data/sources.json`) | свежие новости | публичные ленты, свой User-Agent, таймауты, без обхода ограничений |
| ЕГРЮЛ (egrul.nalog.ru), DaData (при ключе) | данные о компании по ИНН | только по действию пользователя |
| Checko, «За честный бизнес», Википедия, сайт компании | автозаполнение профиля | соблюдаем robots.txt, лимиты размера и времени, внутренние сети запрещены |
| Шлюз LLM организаторов | разрешённые модели | дневной лимит токенов, маскирование реквизитов перед отправкой |
