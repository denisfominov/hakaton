## Правила

1. **Свои файлы — по зонам выше.** Чужой файл — маленьким PR и с предупреждением владельца.
2. **CHANGELOG.md в PR задач не трогаем:** строка — в описании PR, собирает один человек отдельным PR документации.
3. **Не больше двух открытых PR на команду.** Перед PR: свежий `main`, `cd backend && python -m pytest -q`
   (и `npm run build`, если менялся фронтенд).
4. **Контракты** — по [CONTRACTS.md](CONTRACTS.md), задним числом не меняем.
5. **ML-задачи** (A2, A8, B4, B5) — по лекциям курса (docs/ML_LECTURES_INDEX.md): настройка на dev, test один раз,
   точка отсчёта, интервалы.
6. **Не коммитим:** данные кейса, PDF, `.env`, веса моделей, файлы разметки, `backend/data/daily/`.
