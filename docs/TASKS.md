## Правила

1. **Свои файлы — по зонам выше.** Чужой файл меняем только маленьким PR и предупреждаем владельца.
2. **Общие файлы** — отдельным маленьким PR на одно изменение, без переформатирования и «заодно поправил».
3. **CHANGELOG.md в PR задач не трогаем.** Строка для CHANGELOG — в описании PR. Один человек собирает строки в
   CHANGELOG.md отдельным PR документации.
4. **Не больше двух открытых PR на команду.** Сливаем, потом начинаем следующую задачу. Перед PR: влить свежий
   `main`, прогнать `cd backend && python -m pytest -q` (и `npm run build`, если менялся фронтенд).
5. **Контракты** меняются по [CONTRACTS.md](CONTRACTS.md): новое необязательное поле — в своём PR с обновлением
   JSON-схем; несовместимое изменение — отдельный PR с повышением версии.
6. **Платные вызовы** — только с объявлением в чате команды и по одному человеку; для проверок —
   `LLM_PROVIDER=off` или `mock`.
7. **Работа с ML** (A2, A8, B4, B5) — по лекциям курса (docs/ML_LECTURES_INDEX.md): настройка на dev, test один раз,
   точка отсчёта, интервалы.
8. **Данные кейса, PDF, `.env`, веса моделей, файлы разметки** не коммитим.
