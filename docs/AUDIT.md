## Формат ответа (слайды 13–14)

| Вопрос | Статус | Тип утверждений |
|---|---|---|
| Что произошло? | ✅ | `fact` — предложения из текста новости с цифрами и ссылками; участники (NER), сроки и даты, подтверждённость (официальный источник / независимые издания / одно издание), у каждого факта `confirmed` |
| Почему это важно для этой компании? | ✅ | `client` — элементы профиля и данные банка о клиенте |
| Какие последствия возможны? | ✅ | `ai` — риски и возможности по каналам влияния, горизонт |
| Какие действия могут быть релевантны? | ✅ | `ai` — действие, почему, если сделать, если не реагировать, ответственный, срок; вопросы для дополнительного анализа, что отслеживать, сценарии развития (вероятный по оценке банка помечается) |
| Как это оценивает банк? | ✅ | `bank` — цитаты позиции банка из 9 материалов приложения 2 (распознаны OCR) со ссылкой на файл, страницу и дату; совпадение или расхождение с новостью; вывод «с учётом аналитики банка»; вероятный сценарий по оценке банка |
| На чём основан вывод? | ✅ | список источников с номерами, признаки компании, реакция рынка, ограничения |
| Разделение «факты / банк / AI» и JSON по схеме | ✅ | поле `kind` у каждого утверждения; ответ проверяется Pydantic-схемой `AgentResultOut` (`GET /api/agent/schema`): факты, источники, признаки клиента, оценки релевантности, риски и возможности, проверки |
