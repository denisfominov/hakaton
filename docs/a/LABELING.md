# Разметка новостей людьми (A1) — инструкция для команды

Нужно 200 оценок «важна ли эта новость для этой компании». По ним считаем честную точность ленты (задача A2).
Сейчас есть только черновик, который сделали модели, а жюри важна проверка людьми. Платных вызовов нет.

## Кто и сколько

- Четыре человека, у каждого свой файл на **65 пар**: 45 своих и 20 общих.
- **Общие 20 пар** размечают все четверо. По ним видно, насколько люди согласны между собой. Подсказку черновика
  на них не показываем.
- Время: 20–30 минут на человека, примерно 20 секунд на пару.

## Подготовка (один раз)

1. Свежий `main`, окружение backend — как в README («Локально для разработки»).
2. Положить свой файл в `backend/data/gold/`: `labels_annotator1.csv` … `labels_annotator4.csv`.
   - Файлы создаёт `python -m scripts.make_label_sets`. Нужна черновая разметка: она лежит у того, кто запускал
     ночной прогон.
   - Файлы не в git: в них признаки клиентов кейса. Передавайте их напрямую, не через репозиторий.

## Разметка

```bash
cd backend
python -m scripts.label_server --annotator 1 --name "Ваше имя"
```

Откроется страница http://127.0.0.1:8765. Она работает только на вашем компьютере, интернет не нужен.

| Клавиша | Что значит |
|---|---|
| `1` | **не важно**: новость не касается компании или касается слабо и косвенно |
| `2` | **важно**: заметно влияет на деньги, сроки, риски или планы компании, руководителю стоит знать |
| `3` | **критично**: реагировать в ближайшие дни |
| `Space` | согласен с черновиком моделей (только на своих парах; на общих черновик скрыт) |
| `R` / `O` / `N` | риск / возможность / нейтрально (по желанию; без нажатия берётся черновик) |
| `←` `→` | назад и вперёд |
| `Backspace` | снять оценку |
| `C` | комментарий: почему так (очень полезно для спорных пар) |

- Файл сохраняется после каждого нажатия. Закрыть страницу и продолжить потом можно в любой момент: страница
  откроется на первой неразмеченной паре.
- Остановить сервер — `Ctrl+C` в терминале.

## Как решать

- Смотрите на **эту** компанию: отрасль, продукты банка (кредиты — значит, ставка важна), страны ВЭД (значит, важен
  курс), отрасли поставщиков и покупателей.
- **Не соглашайтесь с черновиком по привычке.** Он ошибается, особенно на макро-новостях и на новостях «про всё
  сразу». Если сомневаетесь — нажмите оценку сами и оставьте комментарий.
- Не ищите новость в интернете дольше минуты: оценивайте по заголовку и тексту.

## Что дальше

1. Готовый файл передайте тому, кто собирает разметку.
2. Сборка: `python -m scripts.make_label_sets --merge`. Скрипт делает две вещи:
   - собирает `data/gold/gold_pairs.csv`: для общих пар берётся медиана четырёх оценок;
   - печатает согласие людей (каппа Коэна: 1 — полное, 0 — как случайно) и совпадение людей с черновиком.
3. По `gold_pairs.csv` — метрики A2. В обучение эти пары не попадают.

## Как построена выборка

По лекциям 4 и 5 курса ML:
- **5 демо-клиентов × 40 новостей.** Из них 10 — верх нашей модели, без них не посчитать P@10. Остальные 30 —
  случайные: половина из живых RSS, половина из подборки.
- **Значимые по черновику — около трети случайной части.** Без этого их почти не будет: в живых новостях их около 6%.
- **Исторические решения по ставке не берём:** это 110 почти одинаковых пар.

Итог прогона 2026-10-21: 200 пар, из них 100 живых и 71 значимая по черновику; по 65 пар на человека.
