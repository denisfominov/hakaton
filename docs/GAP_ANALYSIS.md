Состояние `main` на **2026-10-21, после PR #24** (A1 — инструмент разметки). Статусы проверены кодом и замерами,
а не по документам. Платных вызовов при проверке не было.

**Статусы:** сделано · частично · не сделано · отложено (решение команды: размещение на сервере, компактные данные
для хостинга, страница качества, e2e-тест интерфейса). **Кто:** Ч1 — «Агент и интерпретация», Ч2 — «Данные, поиск и
