# Анализ пробелов по требованиям кейса

Состояние ветки `ai-layer` на **2026-10-20**. Каждый пункт проверен прогоном, а не по чтению кода.

**Как проверяли**

1. **Тесты:** `cd backend && python -m pytest -q` — 199 passed на момент прогона, 205 — после тестов контрактов
   (без сети и ключей; e5 — отдельным тестом на скачанных весах).
2. **Docker:** образ из этой ветки (933 МБ). Данные кейса, аналитика банка и веса e5 подключены томами, `PORT=8080`.
   Проверено: `/api/health` (healthy), вход по токену (повтор и подделка — 401), лента демо-клиента, агент для двух
   ролей, ссылки на аналитику банка, живая загрузка RSS (457 новостей из 18 изданий). Память — 1,07–1,37 ГБ.
3. **Сценарий против локального сервера:** данные кейса, e5, LLM выключена. Скрипт прогона хранится вне репозитория,
   его шаги перечислены здесь.
   - 5 демо-клиентов, топ-10 ленты каждого;
   - агент на топ-3 событиях каждого клиента (15 запусков);
   - живая загрузка RSS, затем агент на 10 ранее не показанных новостях;
   - 3 роли на одном событии;
   - уточняющий вопрос, ссылка на PDF банка, создание действия;
   - вход по токену.

**Обозначения:**
- статус: ✅ сделано, 🟡 частично, ❌ нет;
- размер работы: S — до полудня, M — 1–2 дня, L — больше 2 дней;
- риск: насколько вероятно, что жюри заметит пробел и снизит оценку.

**Главные цифры прогона**

| Показатель | Значение |
|---|---|
| Пересечение топ-10 лент у пар демо-клиентов (Жаккар) | среднее 0,51, мин. 0,33, макс. 0,67 |
| Одна новость у разных клиентов | релевантность 40–62 |

| Живая загрузка | 456 новостей из 18 изданий за 6,3 с; RSS в топ-10 клиента — 4–5 |
