## Дефекты (частично сделано)

- Позиция банка — только у новостей о ставке (14 из 50); позицию от модели агент выбрасывает из-за ссылки без `bank:`.
- Отрасль по ОКВЭД неверна у 3 из 5 демо-клиентов.
- Самопроверка ни разу не поменяла ход работы (0 из 50).
- Роли не меняют ни набор, ни порядок действий (5 из 5).
- Трассировка без результатов шагов (0 из 8) и без связи «вывод ← шаги».
- С моделью: таймаут 60 с меньше времени ответа GLM, база заблокирована на время ответа, маршрут не обновлён.
- База не обновляется сама: свежая новость — 2026-10-19, при том что ленты отдают новости 2026-10-21.
- Качество отбора не измерено людьми: размечено 0 из 260 строк; 13 пар «новость ↔ банк» не проверены человеком.
- Безопасность: нет ограничения частоты запросов и описания целевой схемы ролей.
- Выручка 1000 (заглушка) считается настоящей; контрагенты без карточки видны в профиле (В14, В21).
