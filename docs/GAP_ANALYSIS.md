## Как проверяли

- **Тесты:** `cd backend && python -m pytest -q` — 254 passed.
- **Сквозной сценарий:** `python -m scripts.demo_check` на клиентах кейса — 6 шагов «готово», 1 «пропуск» (курс
  рубля: в подборке нет такой новости). С `--online` 2026-10-21 прошло 9 из 9.
- **Замер агента без модели** (`LLM_PROVIDER=off`, копия базы, данные кейса):
  - 5 демо-клиентов × топ-10 ленты, роль «финансовый директор» — 50 ответов;
  - 5 событий клиента U_9250 × 4 роли.
- **Документы** — только как источник цифр платных прогонов:
  - docs/BASELINE.md — стресс-прогон с моделью до C1/C2;
  - docs/MODEL_COMPARISON.md, docs/OVERNIGHT_REPORT.md, docs/GATEWAY_QUESTIONS.md;
  - docs/b/BANK_FOR_EVENT.md, docs/a/FEED_DIVERSITY.md.

**Статусы:** сделано · частично · не сделано · отложено (решение команды 2026-10-21: сейчас только бэкенд).
**Риск** — насколько пробел может снизить оценку жюри.
