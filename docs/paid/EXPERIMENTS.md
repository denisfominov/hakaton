# Эксперименты платной очереди (J3, J6)

Очередь (`scripts/daily_paid.py`) берёт первый эксперимент со статусом `pending` и прогоняет его на тех же запусках,
что J1 (70 запусков BASELINE) и J2 (новые новости дня). Итог пишется сюда, под экспериментом, а статус меняется на
`measured`. **Сама очередь ничего не принимает:** изменение переносит в код человек отдельной задачей с тестами.

Формат: `- status: pending | measured <дата> | skipped`; `- change: route <задача>=<модели через запятую>` (на время
прогона ставится `LLM_ROUTE_<ЗАДАЧА>`) или `- change: prompt <имя>=<файл>` (вариант промпта только на время прогона,
`app/prompts/` не меняется). Новый эксперимент — новый раздел в конце; порядок разделов — порядок запуска.

Первые три выбраны по замерам части 1 (docs/GAP_ANALYSIS.md): сильнее всего они двигают критерии 02 (позиция
банка) и 03 (связь с источниками, минимум ошибок).

## E1 — ответ агента: DeepSeek → GLM вместо GLM → Qwen3.6
- status: pending
- change: route analysis=deepseek/deepseek-v4.1-flash,z-ai/glm-5.3-flash
- criteria: 03, 05; огр. 05
- metric: числа и имена вне входа, доля отброшенных утверждений модели, уход на правила, время ответа, ₽ за запуск
- why: сравнение моделей (docs/MODEL_COMPARISON.md, 2026-10-20) рекомендует этот маршрут: вдвое быстрее и дешевле
  GLM, меньше выдуманного. Его же вводит задача C11 — эксперимент даёт числа до слияния, на тех же запусках.

## E3 — промпт: числа только из входа
- status: pending

- criteria: 03
- metric: числа вне входа, доля отброшенных утверждений модели
- why: в BASELINE 4,1% чисел ответа модели нет во входе, проверка отбросила 40% утверждений модели.

## E2 — промпт: ссылка банка с приставкой bank:
- status: pending
- change: prompt agent_answer=scripts/paid_experiments/agent_answer@E2.txt
- criteria: 02; огр. 02
- metric: доля пунктов «позиция банка» от модели, которые агент принял; сколько отброшено из-за ссылки без приставки
- why: 72–100% пунктов позиции банка от моделей отброшены из-за ссылки без `bank:` (docs/MODEL_COMPARISON.md).
  Задача C1b чинит это в коде; если C1b уже слита — поставить `skipped`.
