# Тезисы аналитики банка по страницам и контрольные вопросы (сырьё для B1 и B4)

Прогон 2026-10-20, `backend/scripts/overnight_bank_claims.py`, потрачено **4,09 ₽**.

Материалы банка — картинки страниц без текстового слоя. Каждая страница (64 страницы, 9 материалов) отправлена
мультимодальной модели Qwen3-VL (единственная разрешённая модель для изображений). Модель выписала тезисы и числа со
страницы и предложила по 2 контрольных вопроса. Вопрос оставлен, только если его ответ дословно (или все его числа)
есть в распознанном тексте этой страницы (`<имя>.ocr.txt`) — проверка без модели.

| Показатель | Значение |
|---|---|
| Страниц / материалов | 64 / 9 |
| Тезисов | 471 |
| Чисел в тезисах | 1267, из них найдены в распознанном тексте страницы — **49%** |
| Вопросов предложено / прошли проверку / оставлено | 128 / 77 / 50 (по материалам по кругу) |
| Как проверен ответ | 46 — дословно, 4 — по числам |

**Половина чисел в тезисах не находится в распознанном тексте страницы.** Возможные причины: распознавание текста
(`ocrmac`) не видит подписи графиков и таблицы-картинки, которые видит Qwen3-VL, — или модель ошибается в числах.
Без человека не различить: тезисы с такими числами нельзя использовать как факты без проверки. Контрольные вопросы
этой проблемы не имеют — их ответы есть в тексте страницы.

## Где файлы

`backend/data/overnight/f/` — не в git: производные от материалов банка (PDF тоже не в git).

- `claims.json` — тезисы: материал, страница, текст, числа;
- `questions_50.json` — 50 вопросов: материал, страница, вопрос, ожидаемый ответ, как проверен;
- `results.jsonl` — сырой результат по страницам; `summary.json` — сводка.

## Как использовать

- **B4** (контрольные вопросы RAG): 50 вопросов с ожидаемой страницей — готовая проверка поиска «нашёл ли нужную
  страницу в топ-k». Перефразировки и подбор порога e5 — в B4.
- **B1** (позиция банка только по событию): тезисы по страницам — словарь тем и чисел каждого фрагмента для сверки
  «фрагмент ↔ событие».

Повторить (продолжает с места остановки):

```bash
cd backend
LLM_PROVIDER=gateway LLM_TIMEOUT=300 LLM_MAX_OUTPUT_TOKENS=4000 caffeinate -i python -m scripts.overnight_bank_claims
```
