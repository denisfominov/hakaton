# Поиск по аналитике банка: замер на 50 вопросах с ожидаемой страницей (B4, базовый замер)

это точка отсчёта перед B1 (позиция банка только по событию) и подбором порогов в B4.

## Что измеряли

- **Вопросы:** 50 контрольных вопросов из ночного этапа (f), docs/b/BANK_CLAIMS.md. У каждого известны документ и
  страница; ответ проверен по распознанному тексту страницы. Вопросы лежат в `backend/data/overnight/f/questions_50.json`
  и в git не попадают: они взяты из материалов банка.
- **Три способа поиска:**
  - **TF-IDF** — по совпадению слов;
  - **e5** — по смыслу, локальная модель эмбеддингов;
  - **гибрид** — оба способа вместе, он работает сейчас по умолчанию.
- **Метрики:**
  - **документ в топ-1 / топ-3** — нужный материал первым или среди первых трёх;
  - **страница в топ-1 / 3 / 5** — нужная страница среди первых 1, 3, 5;
  - **MRR** — средний обратный ранг нужной страницы: 1 — всегда первая, 0,5 — в среднем вторая.

## Что видно

1. **Поиск работает:** нужная страница в первой тройке у 78% вопросов, у случайного выбора — 6%.
2. **Три способа на этих вопросах статистически не различаются:** интервалы почти совпадают (0,56–0,92). Гибрид
   чуть впереди по MRR, но это 1–3 вопроса. Менять способ поиска по этому замеру нельзя.
3. **13 страниц из 64 поиск не видит вовсе.** На них 6 из 11 промахов гибрида. Это страницы-графики и таблицы: их
   распознанный текст — короткие строки, а нарезка на фрагменты отбрасывает абзацы короче 40 символов
   (`bank_rag._chunks`). Чинить — в B4: короткие строки на странице без длинных абзацев склеивать в фрагмент.
4. **Длинный материал — слабое место:** в FI_Strategy (27 страниц) найдена половина страниц; ещё в 3 промахах
   документ найден, а страница — соседняя.
5. **Сгенерированные вопросы завышают качество поиска по словам.** Ответ дословно есть на странице, слова вопроса
   часто тоже. На перефразировках людей TF-IDF находит 2 из 5, e5 и гибрид — 3 из 5. Пользователь спрашивает своими
   словами, поэтому смысловой поиск в гибриде нужен. Чтобы это доказать, нужно 30–50 перефразировок, а не 5.
