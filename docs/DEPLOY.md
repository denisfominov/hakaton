# Развёртывание на бесплатном хостинге

**Статус: подготовлено, не развёрнуто.** Условия хостингов проверены поиском и по документации **2026-10-20**;
перед развёртыванием их нужно перепроверить — бесплатные тарифы меняются. По ответу организаторов «бесплатный
внешний сервер» — любой хостинг с бесплатным тарифом.

## Что готово в коде

| Требование хостинга | Как сделано |
|---|---|
| Порт из окружения | `PORT` (по умолчанию 8000): `uvicorn ... --port ${PORT:-8000}` в Dockerfile, HEALTHCHECK по нему же |
| Проверка живости | `GET /api/health` — открывается ли база (503, если нет), режим LLM, предупреждения; без сети и без загрузки моделей |
| Путь к базе | `DB_PATH` (в образе `/data/alpha.db`, том `/data`) |
| Секреты | только из окружения: `LLM_API_KEY`, `ENTRY_SECRET` (подпись токена входа), `DADATA_API_KEY`. В образ и репозиторий не попадают; `/api/health` предупреждает, если `ENTRY_SECRET` не задан |
| Нет больших файлов в образе | данные кейса (`df_*_hack.csv`), PDF и распознанный текст аналитики банка, веса своих моделей и e5 — в `.dockerignore`; проверено в собранном образе (`find / -name '*.pdf'` — только тестовые файлы пакетов) |
| Сборка без сети на старте | всё ставится при сборке образа; веса e5 — томом или `--build-arg BAKE_EMBEDDINGS=1` |

**Замеры в Docker** (Mac, Docker 29.8, образ `python:3.12-slim`, 2026-10-20):

| Конфигурация | Память | Примечание |
|---|---|---|
| Полная: данные кейса + e5 + NER (natasha), после живой загрузки 457 новостей | 1,07–1,37 ГБ | рекомендуется ≥ 1,5 ГБ |
| Без e5 и NER (`EMBEDDINGS=off`, `NER_ENABLED=0`), с данными кейса | 525 МБ | данные кейса в pandas — ~370 МБ |
| Без e5 и NER, без данных кейса (6 публичных компаний) | 160 МБ | помещается в 512 МБ |

Образ — 933 МБ (зависимости Python ~500 МБ: pandas, scikit-learn, SciPy, onnxruntime, natasha); с весами e5
(`BAKE_EMBEDDINGS=1`) — плюс ~130 МБ. Первый ответ `/api/health` — через ~6 с после старта контейнера.

## Данные кейса на хостинге — нужен ответ организаторов

Данные кейса и аналитика банка не лежат в репозитории и не входят в образ (только для решения кейса). На хостинге
без них сервис покажет 6 публичных компаний и не найдёт аналитику банка. Варианты: загрузить файлы как секретные
файлы или том хостинга (если он есть) либо собрать **приватный** образ с данными в закрытом реестре. Делать это
только после разрешения организаторов — вопрос записан в [QUESTIONS.md](QUESTIONS.md).

## Вариант 1. Cloud.ru Evolution Container Apps — бесплатный объём (рекомендуем)

Ссылки: [free tier Container Apps](https://cloud.ru/docs/evolution/overview/topics/free-tier__container-apps),
[правила акции Evolution Free Tier](https://cloud.ru/documents/promotions/active/evolution-free-tier),
[тарификация Container Apps](https://cloud.ru/docs/container-apps-evolution/ug/topics/pricing). Проверено 2026-10-20.

- Бесплатно каждый месяц для Container Services: первые **25 vCPU·ч и 50 ГБ·ч RAM**.
- «Холодные» экземпляры удаляются, когда нет запросов (поле Idle timeout), — время простоя не тарифицируется.
- Акция действует с 26.12.2024 по **31.12.2026**; участвуют физлица, ИП и юрлица, зарегистрированные в РФ;
  на счёте нужно не меньше 100 ₽ или грант не меньше 100 бонусов; участвовать можно один раз.
- Почему подходит: контейнер на 1 vCPU / 2 ГБ помещается в бесплатный объём на ~25 часов работы в месяц — хватает на
  показ жюри с холодным стартом; данные остаются в России; память хватает и для полной конфигурации.
- Ограничения: диск контейнера не постоянный — база создаётся заново при холодном старте (профили демо-клиентов
  и подборка новостей восстанавливаются сами, действия пользователей теряются); доступные сочетания vCPU/RAM
  и время холодного старта не проверены.

Шаги (не выполнялись):

1. `docker build --build-arg BAKE_EMBEDDINGS=1 -t alpha-intelligence .` (веса e5 внутри образа: томов нет).
2. Загрузить образ в Artifact Registry Cloud.ru (приватный реестр).
3. Создать Container Service: порт 8000 (или задать `PORT`), проверка `/api/health`, холодные экземпляры,
   1 vCPU / 2 ГБ.
4. Переменные: `ENTRY_SECRET` (секрет), `LLM_PROVIDER=gateway`, `LLM_BASE_URL`, `LLM_API_KEY` (секрет, если ключ
   разрешено использовать с сервера — вопрос 3 в GATEWAY_QUESTIONS.md), `DAILY_BUDGET_RUB`.
5. Данные кейса — только после ответа организаторов (см. выше).

## Вариант 2. Render — Free web service (запасной, облегчённый режим)

Ссылки: [Free-тариф Render](https://render.com/docs/free), [типы экземпляров](https://render.com/docs/compute-plans).
Проверено 2026-10-20.

- **512 МБ RAM, 0,1 CPU**; засыпает через 15 минут без входящих запросов, просыпается около минуты.
- 750 бесплатных часов в месяц на рабочее пространство; файловая система временная (теряется при перезапуске,
  деплое и засыпании); постоянные диски на бесплатном тарифе недоступны.
- Подходит только облегчённый режим: `EMBEDDINGS=off`, `NER_ENABLED=0` и **без данных кейса** (160 МБ). С данными
  кейса — 525 МБ, контейнер будет убит по памяти.
- Шаги: New → Web Service → из репозитория с Dockerfile; переменные `EMBEDDINGS=off`, `NER_ENABLED=0`,
  `ENTRY_SECRET`; Health Check Path `/api/health`.

## Что снизит требования к памяти (задача, не сделано)

Данные кейса занимают ~370 МБ в pandas, хотя сервису нужны 115 компаний сегмента и индекс платежей по ним.
Предрасчёт компактной выжимки (только нужные столбцы и компании, категориальные типы) при сборке тома позволит
уложить полную конфигурацию без e5 в 512 МБ — см. docs/GAP_ANALYSIS.md.
