# Вопросы организаторам и принятые решения

Состояние на 2026-10-20. Вопросы про шлюз LLM (формат API, цены, остаток лимита) — в
[GATEWAY_QUESTIONS.md](GATEWAY_QUESTIONS.md).

## Получены ответы — сделано по ним

| Ответ организаторов | Что изменили |
|---|---|
| Локальные модели эмбеддингов (multilingual-e5 и т.п.) использовать можно | e5-small (ONNX int8) в RAG и смысловой близости, TF-IDF — запасной режим (docs/REVIEW.md) |
| Один API-ключ на команду | бюджет и ключ общие для всех разработчиков: по умолчанию `DAILY_BUDGET_RUB=100` |
| 500 ₽ в день на команду, сброс в 03:00 МСК (в раннем ответе было 00:00), остаток не переносится, ключ отключается после дедлайна | бюджетный день — с 03:00 до 03:00 МСК (`BUDGET_RESET_HOUR=3`); кэш ответов моделей для показа без ключа (`backend/data/demo_cache`) |
| «Бесплатный внешний сервер» — любой хостинг с бесплатным тарифом | docs/DEPLOY.md: Cloud.ru Container Apps (бесплатный объём) и Render Free |
| Файл платежей — `df_Uid_payment_hack.csv` | имя и столбцы (`PAYER`, `BENEFICIARY`, `PAY_AMT`, `PAY_CNT`) проверены тестом |
| Фокус — компании из базы; ручной ввод не обязателен | по умолчанию — 5 демо-клиентов кейса и поиск по 115 компаниям сегмента; ручной ввод спрятан за ссылкой; 5 публичных компаний убраны из выборки по умолчанию |
| Вход из Альфа-Бизнеса — через точку входа, регистрация не нужна | макет главного экрана с точкой входа, подписанный токен-заглушка с компанией и ролью (docs/ALFA_BUSINESS_ENTRY.md) |

## Ответа нет — решено так, пока ответа нет

| # | Вопрос | Решено так, пока ответа нет | Что поменяем, если ответ другой |
|---|---|---|---|
| 1 | Можно ли (или нужно ли) использовать LangChain / LangGraph? | **Не используем.** Агент — свой: реестр инструментов с JSON-схемами и правами (`agent_tools.py`), план в JSON, самопроверка, трассировка. Меньше зависимостей, полный контроль над вызовами шести разрешённых моделей, бюджетом и кэшем, тесты без сети | обёртка LangGraph поверх существующего реестра инструментов: узлы «план → инструменты → самопроверка → ответ» (размер M); логика инструментов не меняется |
| 2 | Нужна ли интеграция в тестовый контур Альфа-Бизнеса или достаточно отдельного сайта? | **Отдельный веб-сервис** + макет главного экрана Альфа-Бизнеса (`/alfa-business`) с точкой входа и подписанным токеном | встраивание WebView/iframe или микрофронтенд по описанию в docs/ALFA_BUSINESS_ENTRY.md; токен — от банка (ES256, JWKS) |
| 3 | Как подтверждается связь пользователя с бизнесом? | **Подтверждает банк** при выпуске токена входа (он знает, у кого есть доступ к интернет-банку компании и с какими правами); сервис доверяет подписи и сам ничего не спрашивает. В прототипе токен выпускает макет | если банк не подтверждает — нужна своя проверка (доверенность, роль в ЕГРЮЛ), это отдельный продуктовый поток |
| 4 | Какие сведения о бизнесе можно хранить? | **Только поля приложения 1** (обезличенные данные кейса) и производные от них признаки; кроме этого — только действия пользователя (оценки, избранное, план действий, журнал входов). Персональных данных нет (docs/SECURITY.md) | при запрете хранить производные признаки — считать профиль на лету из данных кейса без записи в базу |
| 5 | Можно ли размещать данные кейса (CSV, PDF аналитики) на внешнем бесплатном хостинге — секретными файлами или в приватном образе? | **Пока нет:** образ и репозиторий без данных кейса; на хостинге без разрешения — только синтетический пример клиентов (docs/DEPLOY.md) | приватный образ в закрытом реестре или секретные файлы хостинга |
| 6 | Можно ли использовать ключ шлюза с сервера демонстрации? | на хостинг ключ не кладём, пока нет ответа; без ключа работает кэш ответов моделей и правила | ключ — секретом хостинга, `DAILY_BUDGET_RUB` под показ |
