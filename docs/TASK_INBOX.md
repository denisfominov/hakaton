# Входящие задачи

Сюда любой из команды дописывает новую задачу одной строкой — в конец файла, ничего выше не меняя. Разбор входящих
переносит строку в [TASK_REGISTER.md](TASK_REGISTER.md) и помечает её «разобрано → <ID>». Порядок разбора — в
реестре, раздел «Как добавить задачу».

Формат строки: `- <дата> · <кто> · <что сделать> · <зачем, если известно>`

Пример: `- 2026-10-22 · Иван · в ленте нет новостей о стали · клиент — металлург, критерий 01`
