## Как обновить подборку

1. Найти публикацию, открыть оригинал, выписать факты своими словами (без копирования абзацев).
2. Добавить объект в `backend/data/real/news.json`: `id`, `title`, `summary`, `body`, `source`, `url`,
   `published_at` (ISO с часовым поясом), `reliability`, при необходимости `official`, `time_approx`, `lang`,
   `title_original`.
3. Перезапустить backend или нажать «Обновить ленту → Перезагрузить подборку».
4. `python -m pytest tests/test_real_dataset.py` — проверит ссылки, даты и уникальность.

правила разбора русскоязычные. Зарубежных новостей при загрузке — не больше 10% от новых.

Репутация изданий — `backend/data/outlets.json` (экспертная оценка команды): официальные источники 0,95,
агентства 0,82–0,9, деловые издания 0,75–0,82, отраслевые 0,55–0,65, общественные и региональные 0,55–0,7,
агрегаторы 0,5–0,6. Холдинг указан, чтобы перепечатки внутри одной медиагруппы не считались независимыми.

## Данные для обучения своей модели

- `backend/data/history/key_rate_decisions.json` — 37 изменений ключевой ставки Банка России с 2020 года. Текст
  составлен по официальной таблице ключевой ставки (cbr.ru/hd_base/KeyRate), дата решения — рабочий день перед
  вступлением в силу (для внеочередных 28.02.2022 и 15.08.2023 — тот же день), поэтому `time_approx: true`.
  Используются только для обучения, в ленте их нет.
- `backend/data/market/prices.json` — цены закрытия IMOEX и акций CHMF, X5, SBER, PIKK, AFLT (режим TQBR) с октября
  2019 года, Московская биржа (ISS API). X5 торгуется на Мосбирже с 2025 года — более ранние новости для неё
  не размечаются.
- Обновить оба файла: `cd backend && python -m scripts.build_market_data` (нужен интернет).
- Свой архив старых новостей (выгрузка с Kaggle, медиамониторинг, CSV с колонками `title`, `date`, `text`, `url`):
  `python -m scripts.import_history archive.csv --name <имя>` — новости, где упомянуты компании или темы публичных
  компаний из профилей, попадут в `data/history/<имя>.json` и будут размечены по реакции рынка.
